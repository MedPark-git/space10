{% if kind=='stock' %}

계정구분 열을 LOT No. 앞에 포함해 주세요. 열 이름으로 읽으므로 다른 위치도 인식합니다. 계정구분이 정확히 ‘제품’인 행만 현황·알림·CSV에 반영합니다. 반제품 등 다른 계정과 빈 계정구분은 창고와 관계없이 제외합니다. 제외 건수는 미리보기에서 확인할 수 있습니다. 아마란스 원본의 No, 입고, 출고 등 추가 열이 있어도 됩니다. 재고는 날짜별로 보관하며, 동일 날짜를 다시 등록해도 이전 자료는 남습니다.

{% elif kind=='mapping' %}

기존 엑셀의 ‘품번 / 품번’ 두 열도 인식합니다. 품번의 앞자리 0이 유지되도록 텍스트 형식으로 복사해 주세요.

{% elif kind=='rules' %}

앞자리 KEY는 ICUBE 품번의 앞 4자리, 끝자리 KEY는 뒤 2자리입니다. 1·2공장은 생산일 + 유효일수 − 1일로 계산합니다. 3년은 1,095일입니다.

기존 ‘KEY값 / KEY값2 / 유효기간’ 양식은 1·2공장으로 읽고 연수를 365일 기준으로 환산합니다. 3공장도 끝자리 KEY(01, 12, CE 등)를 입력해 국내·ODM별로 MTS 제품구분을 연결합니다. 끝자리가 같은 개별 규칙이 공통 규칙(* 또는 빈칸)보다 우선합니다. 개별 연결이 필요한 품번 계열에 적용합니다. 단, 특이사항 관리에서 사용 중인 계열 공통 기간은 이 일반 규칙보다 우선합니다. 42AP·44AP·48AP·49AP는 끝자리와 관계없이 생산일 포함 1,095일이 기본 적용됩니다. 3공장 사용기한은 MTS에 등록된 날짜를 사용합니다.

예: 39FD / 01 → S GEN, 39FD / 12 → HAHA GEN. 두 이름은 동일 제품으로 연결하지만 원래 품명과 전체 품번은 각각 표시합니다. S GEN INJECT / HAHA GEN INJECT는 일반형과 별도로 연결합니다. 다른 동일 제품 별칭은 MTS 제품구분에 제품명 A | 제품명 B처럼 입력하세요.

41로 시작하는 텐던은 재고 품명 또는 규칙에 TIBIALIS가 있으면 Anterior·Posterior와 관계없이 MTS의 TIBIALIS로 연결합니다. 같은 LOT에 사용기한이 다르면 확인 필요로 표시합니다.

{% elif kind=='mts' %}

‘제품명’에는 MTS 원본 제품명을 입력합니다. 규칙의 MTS 제품구분(예: CP, HD) 또는 등록한 별칭으로 연결합니다. HAHA GEN과 S GEN은 동일 제품명으로 인식하고 INJECT형은 별도로 구분합니다. 41 계열 텐던의 TIBIALIS는 Anterior·Posterior를 공통으로 인식합니다. 제조번호 뒤 4자리는 제외해 LOT로 연결합니다. 같은 LOT라도 CP와 HD는 별도로 관리합니다. 같은 제품구분+LOT에 날짜가 여러 개면 등록 전에 충돌을 표시합니다.

제품명이 없는 기존 MTS 자료는 제품구분을 보완한 뒤 등록해 주세요. MTS 사용기한은 그대로 사용하며 1·2공장 계산값을 덮어쓰지 않습니다.

{% else %}
