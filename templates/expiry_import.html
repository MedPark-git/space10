{% elif kind=='mapping' %}

기존 엑셀의 ‘품번 / 품번’ 두 열도 인식합니다. 품번의 앞자리 0이 유지되도록 텍스트 형식으로 복사해 주세요.

{% elif kind=='rules' %}

앞자리 KEY는 ICUBE 품번의 앞 4자리, 끝자리 KEY는 뒤 2자리입니다. 1·2공장은 생산일 + 유효일수 − 1일로 계산합니다. 3년은 1,095일입니다.

기존 ‘KEY값 / KEY값2 / 유효기간’ 양식은 1·2공장으로 읽고 연수를 365일 기준으로 환산합니다. 3공장은 끝자리 KEY를 *로 처리하며 원본 제품명에 포함된 구분문구(예: CP, HD)를 MTS 제품구분에 입력합니다. 3공장 사용기한은 MTS에 등록된 날짜를 사용합니다.

{% elif kind=='mts' %}

‘제품명’에는 MTS 원본 제품명을 입력합니다. 규칙의 MTS 제품구분(예: CP, HD)이 포함된 제품을 찾아 연결합니다. 제조번호 뒤 4자리는 제외해 LOT로 연결합니다. 같은 LOT라도 CP와 HD는 별도로 관리합니다. 같은 제품구분+LOT에 날짜가 여러 개면 등록 전에 충돌을 표시합니다.

제품명이 없는 기존 MTS 자료는 제품구분을 보완한 뒤 등록해 주세요. MTS 사용기한은 그대로 사용하며 1·2공장 계산값을 덮어쓰지 않습니다.

{% else %}
